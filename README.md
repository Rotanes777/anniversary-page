# 纪念日页面模板

一个可以在微信里直接打开的纪念日网页。竖屏滑动，带时间线、照片墙、地图打卡、情书和一堆小交互。

纯静态：一个 `index.html` 加图片和音乐，没有后端、没有数据库、不依赖任何框架。

---

## 长什么样

从上到下八屏：

| 屏 | 内容 |
|---|---|
| 1 | 开场：黑色背景 + 跳动爱心，点一下进入，同时淡入背景音乐 |
| 2 | 大数字：实时显示在一起第几天，从 0 滚上去 |
| 3 | 实时计数：天 / 小时 / 分钟 / 秒，一秒一秒在涨 |
| 4 | 这一路：时间线，一条一条按阅读速度浮现 |
| 5 | 我们的回忆：拍立得照片墙，横向滑动，一次一张，底部有日期刻度轴 |
| 6 | 我们去过的地方：中国地图，去过的城市亮起来，点开看该城市的照片 |
| 7 | 情书：一段一段淡入 |
| 8 | 结尾：两个按钮「要 ❤️」「不要 💔」，要按钮按住撒花 + 泡泡 + 胶片放映，写一个未来的信封，最后是 THE END |

另外还有：

- **时间锁**：设定一个时间，到点之前打开只能看到倒计时
- **编辑器**：在网址后加 `?edit`，连点右上角 ♪ 五下，可以在手机上直接改文字、换照片、调顺序
- **双指缩放**：地图那一屏支持捏合放大

## 五分钟上线

不需要会写代码。

1. 把整个文件夹下载到本地
2. 注册 [Cloudflare](https://dash.cloudflare.com/sign-up)（免费，不用绑卡）
3. 左侧「Workers 和 Pages」→「创建」→「Pages」→「上传资产」
4. 把**这个文件夹里的内容**打包成 zip 一起上传
   （注意：`index.html` 必须在压缩包的根目录，不能套一层文件夹）
5. 项目名随便填，比如 `our-days`
6. 得到一个 `https://our-days.pages.dev` 的链接

这个链接就是你的了，任何人拿到都能打开。

> 也可以部署在 surge / Netlify / Vercel / GitHub Pages，都是纯静态，放哪都行。

## 改成你自己的内容

有三种方式，从简单到灵活：

### 方式一：直接改文件（推荐）

用文本编辑器打开 `index.html`，搜 `<script id="seed"`，会看到一段 JSON，所有文字都在里面：

```json
{
  "startDate": "2025-01-01",      // 在一起的日期，决定「第几天」
  "targetDay": 600,               // 大数字要滚到的目标（留空则显示实时天数）
  "eyebrow": "OUR DAYS",          // 第一屏顶部的小字
  "introTip": "我攒了很久的话",     // 开场爱心下面那句
  "tlTitle": "这一路",             // 时间线标题
  "albumTitle": "我们的回忆",       // 照片墙标题
  "timeline": [                    // 时间线，想加几条加几条
    {"day":"DAY 001","title":"我们在一起了","sub":"从那天开始计时"}
  ],
  "photos": [                      // 照片墙
    {"src":"/img/photo01.jpg","note":"配文","when":"2025.03"}
  ],
  "letter": ["情书，一行一段"],
  "sign": "—— 落款",
  "ask": "要不要还跟我一起",        // 最后一屏的提问
  "reply": "嗯，我也不打算放手。",   // 点「要」之后出现的回答
  "cities": [],                    // 地图上的城市，见下文
  "filmPhotos": [],                // 放映机专用照片池，留空则用 photos
  "endingText": "故事还长，只是一个逗号。"   // THE END 那屏的一句话
}
```

改完保存、重新上传就行。

### 方式二：在手机浏览器里改

网址后面加 `?edit`，比如：

```
https://our-days.pages.dev/?edit
```

连点右上角音乐按钮 5 下，进入编辑模式。可以直接改文字、从相册加照片、拖动顺序。

**注意**：这样改的内容只存在你这台手机的浏览器里，别人看不到。改完要么点「导出全部数据」把 JSON 发给自己，要么就只是自己预览用。

### 方式三：换照片

把 `img/` 里的 `photo01.jpg` ~ `photo20.jpg` 换成你自己的，文件名保持一致就不用改任何代码。

照片建议：长边 800-1000 px，JPEG 质量 75 左右，单张 50KB 以内——太大在手机流量下加载慢。

### 换背景音乐

把你喜欢的歌命名为 `bgm.mp3`，放进 `music/` 文件夹。

- 格式 mp3，码率 96-128k
- 时长不限，会循环播放
- 文件越小加载越快（3MB 左右比较合适）
- 微信不允许网页自动播放声音，所以音乐是在「点开场那一下」开始播的，这是浏览器的限制，不是 bug

### 加地图上的城市

`cities` 数组里每一项：

```json
{
  "name": "威海",
  "lng": 122.12,
  "lat": 37.51,
  "note": "第一次一起看海",
  "photos": [
    {"src": "/img/weihai01.jpg", "note": "2025.06.29"}
  ]
}
```

- `lng` / `lat` 是经纬度，可以在地图网站上查到
- 点地图上那个点会推近放大，然后显示这个城市的照片
- 城市照片放在 `img/` 里即可

代码里内置了 60 个常用城市的坐标（北京、上海、杭州、成都……），在编辑器的「走过的城市」里可以直接点选，不用自己查经纬度。

## 时间锁

默认不锁（`UNLOCK_TS` 写的是 2099 年）。

想让它到某个时间才能打开，搜这段：

```js
var UNLOCK_TS=new Date('2099-01-01T00:00:00+08:00').getTime();
```

改成你要的时间，比如 `'2026-11-23T00:00:00+08:00'`。

- 到点之前打开 → 黑屏 + 倒计时
- 到点之后 → 自动解锁，不用刷新
- 想提前检查内容 → 网址后加 `?open`
- 想重新锁上 → 网址后加 `?relock`

**注意**：这是前端限制，改手机时间就能绕过。它给的是仪式感，不是密码保护。

## 关于隐私

部署到任何静态托管平台后，**任何拿到链接的人都能打开**，不需要密码。

建议：

- 只在你们两个人之间发链接，不要发到群或朋友圈
- 随机域名（如 `our-days-8f2a.pages.dev`）比好记的名字更难被碰到
- 照片会真实上传到托管平台的服务器，介意的话可以把最私密的照片拿掉

## 文件结构

```
.
├── index.html        整个页面：样式 + 数据 + 逻辑，单文件
├── img/              照片，photo01~photo20 是占位图，直接替换
├── music/
│   └── bgm.mp3       背景音乐，需自己放入
├── cover.png         微信转发时的卡片封面
└── README.md
```

整个页面只有一个 HTML 文件，所有 CSS 和 JS 都内联在里面，没有外部依赖、没有构建步骤。改完直接上传就能生效。

## 一些实现细节（给想改代码的人）

- 滚动用 `scroll-snap-type: y mandatory`，一屏一屏吸附
- 照片墙是手写的轮播：`transform: translate3d` + `requestAnimationFrame`，一次只走一张
- 地图是阿里 DataV 的中国省级边界 GeoJSON，简化后内联成 36KB 的 SVG 路径
- 粒子系统统一在 `#fx` 这个 canvas 上跑，爱心、泡泡、花瓣都是同一个循环里渲染
- 时间锁、编辑器状态、信封内容都存在 `localStorage`，换设备或清缓存会丢
